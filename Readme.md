# LifeQuest

> An interactive educational simulation built with Godot to help young people develop practical awareness of civic and legal situations through interactive scenarios.

## Overview

LifeQuest is an educational simulation that explores how game-based interactions can be used to teach young people about civic and legal awareness.

Instead of relying only on theoretical information, LifeQuest places the player inside interactive environments where they can explore, interact with NPCs, and progress through scenario-based experiences.

The current version is an **MVP prototype** containing two levels and two scenarios. It focuses on establishing the core gameplay and interaction systems that can later be expanded into a larger consequence-based learning platform.

---

## The Problem

Young people may learn about laws, rules, and civic responsibilities theoretically, but theoretical knowledge does not always prepare them for making decisions in real-world situations.

LifeQuest explores a more interactive approach:

**Learn → Experience → Decide → Understand**

The goal is to create a safe simulated environment where players can encounter realistic situations, interact with characters, and understand the consequences of their decisions.

---

## Current MVP

The current MVP focuses on the fundamental systems required to create an interactive scenario-based experience.

### Implemented Features

- 2D player movement
- Directional player animations
- Interactive NPCs
- NPC movement and idle behaviour
- NPC-player proximity detection
- NPC interaction system
- Dialogue / textbox system
- Multiple levels
- Scene transitions
- Scenario progression
- Interactive environments
- Open-source game assets

The current prototype contains **two playable scenarios across two levels**.
